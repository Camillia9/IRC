## 🎯 Structure ExecJoin

Voici l'ordre logique que tu devrais avoir :
```
1. Client enregistré ? → return
2. Paramètres valides ? → errMoreParams
3. Nom valide ? → errNoSuchChannel
4. Client déjà membre ? → return (silencieux)

5. Si channel existe déjà (pas nouveau) :
   a. Mode +i actif ? → vérifier si invité, sinon errInviteOnlyChan
   b. Mode +k actif ? → vérifier password, sinon errBadChannelKey
   c. Mode +l actif ? → vérifier limite, sinon errChannelIsFull

6. Ajouter le membre au channel
7. Si nouveau channel → ajouter comme opérateur
8. Broadcaster le JOIN
9. Envoyer le topic
10. Envoyer la liste des membres
